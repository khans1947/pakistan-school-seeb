To replace the school logo site-wide:
  1. Replace school-logo.png (square crest, ~256–512px)
  2. Optionally update school-logo-hd.png (higher res, ~512px)
  3. Optionally update school-logo-pin.png (circular crop for map)

To change the campus photo used in branch panels:
  Replace campus-photo.jpg
